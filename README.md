# PAES M1 — Guías semanales

Sitio estático con las guías semanales de preparación para la Prueba de Matemática 1 (PAES M1):
teoría, ejercicios tipo PAES con espacio para responder y claves al final de cada guía.

## Contenido

- `index.html` — portada con las guías disponibles.
- `semanas/semana-NN.html` — guía de cada semana (lee también el PDF).
- `semanas/semana-NN.pdf` — descarga en PDF.

## Uso

Abrir `index.html` en el navegador (no requiere servidor ni conexión).
